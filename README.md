# CodeAlpha Project 1: Hangman Game

A text-based Python Hangman game. The player guesses a hidden word one letter at a time.

## Features
- Chooses randomly from five predefined words.
- Allows up to six incorrect guesses.
- Validates input and prevents repeated guesses.
- Displays the hidden word and remaining attempts.
- Allows the player to start another round.

## Requirements
- Python 3.8 or later
- No third-party packages required

## Run
```bash
python hangman.py
```

## Concepts used
`random`, strings, sets, lists, loops, conditionals, functions, and input validation.
